About

I’m a Senior Software Engineer with over 9 years of experience building secure, cloud-native web applications. I care about the details that connect a thoughtful user experience with reliable, scalable engineering.

I specialize in React and Next.js, backed by .NET Core and Node.js. My work spans frontend architecture, microservices on Azure and AWS, and the CI/CD and observability that keep applications running smoothly.

Performance, accessibility, and security are central to how I build. From Core Web Vitals and WCAG accessibility to OAuth2 / OIDC authentication, I focus on software that works well for the people using it.

Recent work includes AKS / Kubernetes migrations, SSR and ISR, event-driven services with Kafka and Service Bus, and automation with GitHub Actions, Docker, and Terraform.
